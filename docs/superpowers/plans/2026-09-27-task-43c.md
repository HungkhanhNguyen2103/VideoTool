# Task 43c 2.5D Parallax Implementation Plan

**Goal:** Ship opt-in depth-displacement parallax with depth-map generation, storage, jobs, Remotion fallback, UI, and verification.

**Architecture:** Depth Anything V2 Small runs in the existing Python inference service and returns a 16-bit PNG plus score header. Node stores score and depth file references conditionally, derives eligibility from a named TypeScript threshold calibrated against all Kodak images, and stages matching maps for a raw WebGL Remotion layer. Existing Ken Burns remains the fallback.

**Scope:**
- Calibrate all 30 Kodak image scenes before choosing `DEPTH_MAP_ELIGIBILITY_THRESHOLD`.
- Add Python `/api/depth`, local model download docs, and shared inference locking.
- Add project/scene contracts, invalidation, conditional writes, depth jobs and duplicate-pending protection.
- Add Remotion parallax props, raw WebGL displacement, `chromiumOptions.gl = angle`, graceful fallback, and Studio controls.
- Add tests and run full typecheck/lint/test/build plus production timing and still renders.

**Verification:** calibration distribution and borderline composites; lab/boardroom 0/50/100 stills, edge crop, film-look+parallax, transition frame, 9:16 still; 24s 1920x1080 timings for off/on and film-look combinations.
