# Task 85 SFX Reliability and Mixing — Implementation Plan

**Goal:** Make SFX batch generation resilient and voice-free, and make project SFX loudness consistently 0.5 relative to mastered voiceover in FFmpeg and Remotion.

**Architecture:** Keep the Freesound client backward compatible while adding structured selection results, a shared API-request limiter, retry handling, and local candidate scoring. Persist only the project-level `sfxVolume`; normalize temporary SFX copies at render time through a shared video helper, leaving stored audio untouched.

**Tech Stack:** TypeScript, Zod, Vitest, Freesound API v2, FFmpeg/ffprobe, React Studio.

**Spec:** User-provided Task 85 prompt and approved follow-up adjustments in this conversation.

## Global Constraints

- No new dependencies; npm tests never access the network.
- Preserve the legacy Freesound wrapper and existing SFX prompts; do not regenerate prompts.
- Keep `/apiv2/search/text/` until a real request verifies the replacement endpoint parameters.
- Space API requests by at least 1.1 seconds; retry at most 3 attempts with exponential backoff, jitter, and `Retry-After`.
- Stop after 3 consecutive scene-level persistent 429 outcomes; return the temporary-block message in the job result.
- Normalize only temporary render-time copies; stored source SFX is never modified.
- Stage only Task 85 files/hunks; leave existing untracked Task 82 plan untouched.
- Keep per-file line endings; new files use LF. Update AGENTS and module docs in the feature commit.

## Review Focus

- Concurrent calls must share the 1.1-second API spacing; retry attempts also consume a slot.
- Persistent 429s stop after three consecutive scene outcomes, not after three total attempts across the batch.
- Only-missing retries exclude scenes with an existing SFX and scenes without a prompt.
- Scoring rejects voice-like results even when their rating is higher than a relevant non-voice result.
- Both renderers normalize short and long clips, apply the same project gain, and preserve voiceover level during FFmpeg mixing.

1. **Pure query/scoring rules and prompt:** test first; preserve Unicode, map the specified Vietnamese SFX phrases, cap/dedupe queries at three, reject unknown non-ASCII phrases, score 15-result fixtures, and update visual-prompt guidance without changing existing scene data.
2. **Freesound client:** test structured reasons, compatible wrapper, one search returning 15 candidates, CC0/duration/negative query parameters, limiter spacing, 429/5xx/network retries, `Retry-After`, and non-retryable 4xx with injected fetch/clock/random.
3. **Batch outcomes and Studio retry:** test per-scene outcomes, no-prompt skips, only-missing selection, three-consecutive-429 early stop, final summary/job result, route payload, UI counts, and retry button. Keep failure detail in job logs/results rather than project/file schema.
4. **Project volume and renderer parity:** test `sfxVolume` validation/default/legacy conversion/setter/duplicate and Studio save behavior. Add fake-runner tests for shared render-time normalization; integrate FFmpeg with `amix=normalize=0` only when supported (FFmpeg 4.4+) and Remotion staging/props with the same target and gain.
5. **Docs and verification:** update AGENTS, video/project/Freesound module docs; run focused tests, typecheck, lint, full tests, and build. When services are available, run the real diagnosis, same-project before/after batch, battle-scene review, both-engine `ebur128` check, and Studio screenshots; mark unavailable checks pending without fabricating results.
